## Description

Elemental Canvas is an interactive Python art program that lets users create animated effects inspired by fire, water, earth, and air using mouse clicks and keyboard controls. It combines digital drawing and particle animation to let users make colorful, moving artwork.

## Features

- **Element selection:** Press the number keys (1–4) to switch between fire, water, earth, and air. Each element will have its own colors, shapes, and movement patterns.
- **Interactive drawing:** Click or drag the mouse to spawn particles at the cursor's position, allowing the user to paint animated effects on the screen.
- **Particle animation:** Use Python lists, loops, random values, and simple movement calculations to animate particles that move and fade over time.
- **Clear and save:** Press a key to clear the canvas; if time permits, save a screenshot of the artwork as an image file.
- **On-screen instructions:** Display the current element and basic keyboard controls so users can understand how to interact with the program.

## Challenges

- Learning more about **Pygame** to create a window, process keyboard and mouse input, and animate drawings smoothly.
- Designing four particle behaviors that look distinct while keeping the program responsive.
- Learning how to save artwork to an image file if there is enough time.

## Outcomes

**Ideal Outcome:** A polished, interactive art program with all four elements, smooth animated particles, on-screen controls, and an option to save artwork.

**Minimum Viable Outcome:** A working Python program where users can switch between at least two elements and click to create moving, fading particles. This will still demonstrate interactivity, animation, and digital art techniques.
